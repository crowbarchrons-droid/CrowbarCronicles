Privacy Policy - Crowbar Chronicles

This personal application uses TikTok Login Kit and the Content Posting API only to upload videos chosen by the account owner.

It reads basic profile information (user.info.basic) and uploads videos (video.upload, video.publish). Access tokens are stored only on the owner's own computer. No data is shared with third parties, sold, or used for advertising.

Access can be revoked at any time in TikTok settings under Security and permissions.
